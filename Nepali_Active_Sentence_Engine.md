# Nepali Active Sentence Engine — Ready Reckoner

## The core idea

**Hindi sentence structure + Nepali postpositions/case markers + Nepali verb patterns + familiar shared vocabulary**

Because Hindi and Nepali are structurally close, this can reduce the amount you need to actively memorize.

### Example 1

**Mujhe kal Kolkata mein jaana hai.**

→ **Malai bholi Kolkata ma janu chha.**

You mainly need to know:

- **malai** = mujhe
- **bholi** = kal
- **ma** = mein
- **janu chha** = jaana hai

### Example 2

**Mujhe agle hafte tak kaam karna hai.**

→ **Malai arko saptah samma kaam garnu chha.**

Here the important reusable pieces are:

- **malai** = mujhe
- **samma** = tak
- **kaam garnu chha** = kaam karna hai

The objective is to become able to generate new sentences by substitution rather than memorising hundreds of complete sentences.

## Active Nepali framework

### 1. Person / object markers

| Person | Subject / base | Object / recipient | Agent | Possessive |
|---|---|---|---|---|
| I | ma | malai | maile | mero |
| you (informal) | timi | timilai | timile | timro |
| he/she | u | ulai | usle | usko |
| he/she (respectful) | uha | uhãlai | uhaãle | uhaãko |
| we | hami | hamilai | haamile | haamro |
| you (polite) | tapai | tapailai | tapaile | tapaiko |

### 2. Core postpositions

- **ma** → mein
- **samma** → tak
- **bata** → se / from
- **sanga** → ke saath / ke paas
- **ko / ka / ki** → ka / ke / ki
- **lai** → ko / ko lekar / for
- **dekhi** → se / since
- **bhanda** → se / than
- **barema** → ke baare mein
- **lagi** → ke liye
- **garda** → ki wajah se / karne par

### 3. Seven core tense patterns

1. Past indefinite
2. Past continuous
3. Present indefinite
4. Present continuous
5. Present perfect
6. Future indefinite
7. Future continuous

Use one common verb at a time and practise the pattern across persons and numbers.

### 4. Sentence-building principle

Start with the Hindi structure and replace the key grammatical pieces with Nepali.

The goal is a small **sentence-building engine**, rather than memorising hundreds of complete sentences.

### 5. Learning rule

**Understand the building blocks → substitute words → generate your own sentences.**

Keep the active vocabulary and grammar set narrow. Use broad Nepali input for comprehension, but actively practise a small set of reusable building blocks and generate new sentences from them.

## Important grammar distinctions

### ho vs chha

**ho** → identity / classification

**U shikshak ho.** → He/she is a teacher.

**chha** → location / state / condition / existence

**U gharma chha.** → He/she is at home.

**Yo ramro chha.** → This is good.

This is a useful basic distinction, not an absolute rule for every Nepali construction.

### bhayeko

**bhayeko** can be a participial form describing a noun, not only part of a perfect construction.

**Kampanima bhayeka sabailaai...**  
→ company mein maujood / jo company mein the, sabhi ko...

**Sujhaab garnu bhayeko bichaar**  
→ the idea that he/she suggested.

## Core reusable patterns

**verb + nuparne** → have to / must

- **garnuparne** → karna padta hai
- **januparne** → jaana padta hai

**verb + na saknu** → cannot

- **bolna sakdina** → I cannot speak

**verb + dai chhu** → I am doing

- **gardai chhu** → I am doing
- **jadai chhu** → I am going

**verb + nechhu** → explicit future

- **garnechhu** → I will do
- **aaunechhu** → I will come

**malai + verb + nu + chha** → I have to / I need to

- **malai janu chha** → I have to go

**malai + verb + na + dinuhos** → let me do

- **malai garna dinuhos** → let me do it / allow me to do it
